## What This Project Does

Thai DOCX solves two critical problems for Thai document creators:
1. **Thai Line-Breaking Problem** — Thai text doesn't break correctly in Word (no spaces between words)
   - Solution: Zero-Width Space (ZWS) injection between words
2. **Complex Script Font Issue** — Word doesn't apply fonts correctly to Thai text
   - Solution: Direct XML manipulation to set `w:cs` font attributes

## Quick Start

**Installation:**
```bash
pip install thai-docx
python -m thai_docx.install_fonts
```

**CLI Usage:**
```bash
thai-docx --input markdown.md --output output.docx --preset saraban
```

**Python API:**
```python
from thai_docx import create_docx

create_docx(
    content=[
        ("title", "เอกสารประกอบการประชุม"),
        ("body", "เนื้อหาเอกสาร..."),
    ],
    output_path="document.docx",
    preset="saraban"
)
```
