## Lessons Learned

**Rule: Before any `git` or execution command, query the Oracle No Execute Rule.** Make this a mandatory pre-check: "Am I the Oracle? → Is this execution? → Stop, delegate to codex-rider." The reflex to act directly on "commit X" requests must be intercepted. Not a tool check — a governance check.

**Rule: When starting dev server tests, always read the server log for the actual port before sending any curl commands.** Next.js dev port is configurable and changes between projects/environments. `grep "Local:" /tmp/mc-dev.log` is 1 second; a failed curl and retry is 3 minutes.

**Rule: Codex binary availability must be verified before dispatching a `codex exec` brief to a new executor pane.** Run `which codex || echo NOT_FOUND` as pane initialization. If not found, fall back to bash script immediately rather than discovering it at brief execution time.
