## Honest Feedback

**Three friction points this session:**

1. **Git identity not set on most oracle repos** — About half the oracle repos lacked `user.email` config, causing `fatal: empty ident name` on commit. This is a recurring operational tax: every time we touch a fresh oracle repo we hit this. The fix each time is adding `-c user.email=... -c user.name=...` to the git command, but we've done this 10+ times and haven't automated it. Setting a global git config for the E0XXXXXXXXX identity would eliminate this permanently.

2. **Rebase conflict cascade on aeimathes and lens** — The fleet sync commits on these two repos created diverged histories with origin because other processes (the aeimathes session itself) had already pushed newer commits while we were working. The resulting rebase conflicts required multiple recovery attempts — stash, abort, checkout --theirs, detached HEAD — before landing correctly. The fetch-first protocol (from Nat's patterns, which Aeimathes just researched!) would have prevented this. We documented the lesson and then immediately didn't apply it.

3. **maw hey queueing instead of delivering** — Both research missions to Zeus got queued to ψ/inbox instead of delivered, because Zeus's pane was "not idle: context used." There's no automatic retry or notification when the pane becomes idle. The workaround (waking Aeimathes instead) worked but required understanding the fleet topology mid-session. A `maw hey --wait` or idle-delivery mode would make this smoother.

## Lessons Learned

1. **Fetch-origin-first before every commit cycle in shared repos** — `git fetch origin && git rebase origin/main` before staging prevents diverged history push rejections. Apply this as the default pattern even for oracle repos that "shouldn't" have remote changes.

2. **Set global git identity for fleet account at session start** — `git config --global user.email` check + set once per session eliminates the `-c user.email=...` per-command tax across all oracle repos.

3. **When maw queues instead of delivers, check if the target pane IS this session** — In a Tham-Zeus merged architecture, "send to Zeus" = "do it yourself." Recognize the topology before trying to delegate.

4. **Research → implement in same session compounds value** — Aeimathes researched Dynamic Task Router; we implemented it same session while the context was hot. Pattern: don't defer implementation to "next session" when the research is fresh.
