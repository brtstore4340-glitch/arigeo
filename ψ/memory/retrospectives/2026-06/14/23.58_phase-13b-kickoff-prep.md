## Lessons Learned

1. **Proactive prep beats passive monitoring** (generalizable: coordination pattern). When delegating async work to an agent (Codex-01 fixing PR), don't block waiting for status. Immediately shift to independent work (kickoff prep) that doesn't depend on the async task. Result: 2 independent streams complete in parallel instead of serial. This pattern scales to 5+ parallel agents: brief all, start all async, work on orthogonal tasks while they execute.

2. **Charter complexity is justified by sprint length** (generalizable: planning). A 3-week sprint with 5 pass/fail gates + 3 specialized roles requires detailed charter (roles, timeline, contingencies, success criteria). Don't apologize for detail when it reduces Monday confusion. But separate "briefing version" (terse) from "reference version" (detailed) — distribute concise version for quick read, reference version for deep dives.

3. **PR blocker discovery delay cascades** (generalizable: monitoring). When you hand off a critical PR (merge deadline in 72h), check it within 30 min of handoff, not 2h later. Stale status = lost diagnosis time. Pattern: async handoff + immediate follow-up check (5 min) = early warning.

4. **Worktree isolation is safety, not burden** (generalizable: background work). Enforce worktree isolation for background jobs (prevents clobbering user's working copy). It adds one step (EnterWorktree), but it's non-negotiable for multi-agent safety. Design sessions to expect it; don't fight it.
