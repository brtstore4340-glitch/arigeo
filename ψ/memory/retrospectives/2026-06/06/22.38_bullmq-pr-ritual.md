## Lessons Learned

1. **On large branches, query commits individually — not branch diffs.** `git diff main...HEAD --stat` across cleanup + feature commits produces noise. Preferred: `git log main..HEAD --oneline` → pick feature commit → `git show <hash> --stat`.

2. **Branch-with-no-PR is a ship waiting to happen.** The BullMQ branch sat 24h with no PR. `/recap` caught it. The protocol works — run it every session.
