## Lessons Learned

1. **Special characters in paths need explicit testing** — Unicode paths (ψ, Thai characters, etc.) may not behave the same as ASCII paths. Always verify path expansion before writing files in unfamiliar directories.
2. **Submodules have independent state** — When writing to a submodule's ψ/, I must check if that submodule exists as a real directory first, not assume it mirrors the parent structure. Reading the .gitmodules or checking `git config --file .gitmodules` would have caught this.
3. **Git plumbing is useful when porcelain is blocked** — `git update-ref` is lower-level and less subject to safety hooks than `git branch` commands. Knowing the plumbing layer available when porcelain fails.
4. **Scheduling with cron every 20 minutes** — This is viable for monitoring recurring school assignments. The 20m cadence keeps things fresh without spam. Good for patterns that need continuous visibility (e.g., student progress tracking, daily homework rotation).
