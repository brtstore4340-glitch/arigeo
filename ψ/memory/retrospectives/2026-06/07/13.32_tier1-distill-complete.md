3. **Lazy-loaded rules scale better** — 161-line hub + 4 command files faster than 376-line monolith. Load rules on demand.

4. **Composition over monoliths** — 3-phase pipeline more testable than one big function. Each phase fails independently.

5. **Integration scripts bridge gaps** — bash orchestrator makes 3 independent functions feel like one coherent system.
