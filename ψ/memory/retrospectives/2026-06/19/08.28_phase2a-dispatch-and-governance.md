### Rule 2: Parallelization Windows Are Precious

**Application**: When sequencing multi-team work, always ask: "What can run in parallel?" Unlock those paths immediately.

### Rule 3: Governance Efficiency = Clear Routing + Async Coordination
**Pattern**: Briefings (Epiteles) work async; directives (Codex-01) need urgency. Match transport to urgency: inbox for strategic, maw for tactical/urgent.

**Application**: Before routing, ask "How urgent is this?" and pick transport accordingly. Async is fine for planning; urgent work needs real-time signal.
