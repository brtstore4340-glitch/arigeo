## Lessons Learned

**Lesson 1**: Investigate blockers by data, not time. When a task appears "stuck," check git commits, maw status, and file timestamps before escalating. Silence ≠ failure; silence might mean waiting-for-input.

**Lesson 2**: Token budgets are operational constraints, not guidelines. At 75%+ consumption, every decision (spawn agents? read files? create new docs?) carries marginal cost. Discipline compounds: skipping one 5K-token side quest leaves headroom for critical work later.

**Lesson 3**: Architectural patterns replicate at every scale. RTK's 3-tier parsing (Full → Degraded → Passthrough) mirrors the federation's bootstrap strategy (Full federation → Degraded without realtime sync → Passthrough fallback). When you find a pattern that works, it propagates.

**Lesson 4**: Non-negotiable rules protect resource-constrained systems. The RTK Protocol (mandatory RTK before work) and Headroom always-on compression aren't bureaucracy; they're resource-guardrails that prevent token runaway. User enforcement (not system enforcement) makes them credible.
