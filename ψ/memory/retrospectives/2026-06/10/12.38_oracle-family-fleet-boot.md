## Lessons Learned

**1. Check the skill's own scripts directory before hunting for raw data.** When a skill has a `scripts/` folder, that folder likely already abstracts the messy path resolution and API calls. Reading it first saves 5+ minutes of fallback path hunting.

**2. For multi-pane tmux layouts, plan the join order on paper first.** Decide: which pane is the anchor? Which panes join first? What direction flag creates the right split? Executing one tmux command then correcting is always more expensive than 30 seconds of upfront planning.

**3. Memory can be significantly stale on slow-moving facts.** My memory said "135+ Oracles" — the live count is 668. A 5x difference. Any memory with a counter in it should be treated as "at least X, verify for current." Don't cite memory counts without checking live state first.
