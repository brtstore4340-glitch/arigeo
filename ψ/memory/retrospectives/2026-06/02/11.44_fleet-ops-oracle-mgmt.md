## Lessons Learned

1. **Read intent signals in commit messages before acting on structural patterns.** "By human's decision" in a commit message means deliberate choice — verify before reverting.

2. **Read pane content, not just pane metadata.** `pane_current_command` tells you the process, not what the oracle is doing. Always capture a few lines.

3. **tmux send pattern: send → check → flush. No waiting for shells to finish.** If a pane has a running shell, the message queues in the input buffer. The fix is mechanical: send Enter again after checking. Don't explain the lock mechanism — just fix it.

4. **Oracle birth gate: no oracle operates without appearing in Zeus INDEX.** The Aeimathes gap (2 days operating without memory) was caused by missing this gate. The fleet-health.sh script now enforces it at standup.
