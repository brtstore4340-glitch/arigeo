## Lessons Learned (Generalizable)

**Lesson 1: Past deadlines eliminate optionality.**  
When a deadline has passed and a default fallback exists, debating alternatives is academic. Execute the safe path immediately. This pattern applies to any escalation where time is already spent.

**Lesson 2: Autonomous execution paths are resilient under pressure.**  
Of three options, the one requiring zero external coordination is the best default when time is short. "Path B" required only Codex-01 (internal, no waiting for cluster admins). This principle: "minimize external dependencies under time pressure" generalizes to system design, incident response, and decision-making.

**Lesson 3: Worktree isolation is a non-negotiable pattern for background jobs.**  
Even a 3-line edit in a shared checkout is a collision risk. The EnterWorktree → work → ExitWorktree pattern costs 20 seconds and buys collision safety. Make it automatic, not optional.

**Lesson 4: Real timestamps from session data > conversation memory.**  
The background subagent returned 5 exact timestamps from .jsonl (15:13, 15:13, 15:14, 15:15, 15:17). Conversation memory gives approximate order; .jsonl gives proof. When available, use real data for audit trails.
