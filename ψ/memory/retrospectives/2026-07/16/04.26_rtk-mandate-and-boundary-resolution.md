## Lessons Learned

- **When recommending between a reversible option and a harder-to-undo one for something with wide blast radius, default the "Recommended" framing toward the reversible option first** — treat the harder option as an escalation path if the soft version doesn't hold, not the starting point, even when the harder option is technically the more complete enforcement.
- **When a shared scratchpad/tmp filesystem fills from pre-existing, unrelated cruft, ask about clearing it the first time it's discovered** — treating it as "clear my own files and move on" just defers the identical failure to the next heavy operation in the same session.
- **When a tool/hook's exact JSON input schema isn't documented locally, a disposable debug hook that dumps raw stdin to a file, exercised via one real invocation, is faster and more certain than inferring field names from changelog prose.**
- **After reverting a config change, confirm with `git diff` that the diff is actually empty** rather than assuming the Edit tool's inverse operation matched the original exactly — cheap to check, expensive to be wrong about for something about to be pushed.
