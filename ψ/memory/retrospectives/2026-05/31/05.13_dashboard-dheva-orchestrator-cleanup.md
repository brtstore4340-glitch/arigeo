## Lessons Learned

1. **Delegate ต่อหลัง rate limit = wrong pattern** — ถ้า primary agent rate-limited, pause และถาม human priority ก่อน ไม่ใช่ chain ต่อโดย assume ว่า "ต้องทำทันที"

2. **Surface root cause ก่อน delegate** — identify ปัญหาที่แท้จริง (Node version, API key, permission) ก่อน spawn agent แทนที่จะให้ agent ค้นหาเอง ประหยัด token และลด chain length

3. **Windows binary ใน WSL = Windows shell context** — binary ที่อยู่ใน `/mnt/c/` หรือ Volta path รัน Windows shell ไม่ใช่ WSL bash ต้องตรวจก่อน assume environment
