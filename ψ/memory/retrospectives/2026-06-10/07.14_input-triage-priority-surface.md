## Lessons Learned

**Lesson 1: Handoff currency is not status.**  
A handoff written at Phase 3 becomes fiction by Phase 9. Don't trust point-in-time claims without verification. Rule: Before surfacing any "pending" list to a user, verify ≥50% of items against current reality (grep, git, gh pr state). Stale pending lists break trust.

**Lesson 2: Triage is a force multiplier for gated agents.**  
When an agent is blocked on "which task?", surfacing a prioritized list (not a flat queue) unblocks them in 1 session instead of asking follow-up questions. Invest in triage early.

**Lesson 3: Parallel sessions create invisible work.**  
Session 07:17 (PHASE 6) was running simultaneously with 07:14 (triage). Neither tracked the other. Result: user didn't know Phase 6 shipped until I ran /dig. Rule: End-of-session sync (via /rrr or /recap) is non-negotiable when multiple sessions are active in parallel.
