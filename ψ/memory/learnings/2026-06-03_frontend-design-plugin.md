# Learned: frontend-design Plugin (Anthropic Official)

## Key Insights

1. **Prompt-only architecture** — the plugin is a single SKILL.md with structured design thinking instructions. No runtime code, no dependencies. Pure prompt engineering.

2. **Anti-AI-slop rules** — explicit blacklist: Inter/Roboto/Arial/Space Grotesk, purple gradients on white, predictable component patterns. Always pick a bold intentional direction.

3. **Design Thinking before coding** — 4-step framework: Purpose → Tone → Constraints → Differentiation. Commit to extreme (brutal minimal, maximalist, retro-futuristic, etc.) before writing a line.

4. **Motion principle** — one well-orchestrated page-load with staggered `animation-delay` > scattered micro-interactions. CSS-only for HTML, Motion library for React.

5. **ERP application** — for orry-serenity Thai B2B ERP: `luxury/refined` or `editorial/magazine` aesthetic suits the context. Pair distinctive display font + Sarabun for Thai body text.
