   **To generate PDF from HTML:**
   
   **Option A: Browser Print (Recommended)**
   ```
   1. Open the HTML file in a web browser

   3. Select "Save as PDF"
   4. Adjust margins: 2cm all sides
   5. Enable "Background graphics"
   ```
   
   **Option B: Using Node.js (if installed)**
   ```bash
   npm install puppeteer
   node << 'EOF'
   const puppeteer = require('puppeteer');
   
   (async () => {
     const browser = await puppeteer.launch();
     const page = await browser.newPage();
     await page.goto('file:///route/mission-control/ψ/memory/learnings/2026-06-07_session-summary-TH.html');
     await page.pdf({
       path: '2026-06-07_session-summary-TH.pdf',
       format: 'A4',
       margin: { top: '2cm', bottom: '2cm', left: '2cm', right: '2cm' }
     });
     await browser.close();
   })();
   EOF
   ```

   ```bash
   wkhtmltopdf 2026-06-07_session-summary-TH.html 2026-06-07_session-summary-TH.pdf
   ```
