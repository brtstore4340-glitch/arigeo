# Clear Decision Gates Accelerate Execution

## The Pattern

Framing major decisions as **binary or multi-choice questions with clear trade-offs** (not open-ended asks) enables fast, confident execution.

### Session Evidence

Phase 13 kickoff moved from briefing → kickoff meeting → approval decision → fleet activation in **80 minutes** because each decision was structured:

| Decision | Frame | Result |
|----------|-------|--------|
| Phase 13 scope | "APPROVE / CONDITIONAL / DEFER" (not "should we do it?") | User chose APPROVE immediately |
| Data access | "Confirmed / Partial / Unknown" (not "is data ready?") | Framed as blocker-detection |
| Cluster limit | "Accept 2/week / Modify / Reject" (not "is this OK?") | User confirmed without debate |
| Leadership | "Aeimathes lead / Alternate / Co-leads" (not "who leads?") | User confirmed Aeimathes immediately |

**Speed gained**: Each decision took 1–2 min instead of 5–10 (no open deliberation phase).

---

## Why This Works

1. **Reduces cognitive load** — Don't ask "what should we do?" Ask "do you prefer A, B, or C?"
2. **Signals confidence** — Framing options shows you've thought through trade-offs
3. **Enables quick escalation** — If user hesitates, you can pivot ("sounds like you want to modify, let's explore which constraint to relax")
4. **Prevents analysis paralysis** — Open-ended questions invite endless deliberation

---

## Practical Application

### Before (open-ended)
> "So what do you think about Phase 13? Should we do it?"
> (User: "Um, maybe? Tell me more...")
> (Leads to 20-minute back-and-forth)

### After (gated)
> "Phase 13: APPROVE (6,000 TS, 10-week timeline), CONDITIONAL (modify constraints), or DEFER?"
> (User: "Approve and start validation sprint")
> (80 seconds, done)

---

## When to Use

- **Strategic decisions**: Phase kickoffs, scope approval, timeline trade-offs
- **Activation gates**: Should we start NOW or schedule? Ship or hold?
- **Constraint discussions**: Hard limit acceptable, or needs adjustment?

## When NOT to Use

- **Exploratory questions**: "What could we build?" (genuinely open)
- **Brainstorming**: Frame later, explore first
- **Problem diagnosis**: Open questions help here (find the real blocker first)

## Generalization

Apply decision gates to:
- Weekly standup: "Status: on-track / at-risk / blocked?"
- PR reviews: "APPROVE / REQUEST-CHANGES / HOLD for scope clarity?"
- Oracle activations: "Start now / Schedule day X / Defer to phase Y?"

Binary + multi-choice framing works anywhere speed + clarity matter.
