# Learned landing-page-guide-v2

1. **Conversion + Design ไม่ขัดกัน** — skill นี้สอนให้ทำหน้าที่ convert AND สวย พร้อมกัน โดยใช้ 11 Essential Elements Framework
2. **เลือก 1 aesthetic ให้ชัด** — minimalist / maximalist / retro / organic / editorial / brutalist เลือกแล้ว execute สุดๆ อย่า blend
3. **Design system ก่อนเขียน code** — กำหนด fonts, colors, spacing, motion tokens ก่อนเริ่ม component ทุกครั้ง
4. **Anti-patterns ที่ต้องหลีก** — purple gradients, Inter/Roboto/Arial, stock photos, generic card layouts, inconsistent spacing
5. **Stack**: Next.js 14+, TypeScript, Tailwind, ShadCN UI (customize heavily), Framer Motion
