# ✅ Build Fix — next-intl Configuration Updated

## Problem Identified

Build was failing during static page generation:
```
The `locale` parameter in `getRequestConfig` is deprecated
A `locale` is expected to be returned from `getRequestConfig`, but none was returned
Error occurred prerendering page "/en/about"
```

The i18n/request.ts was using the deprecated next-intl v3.21 API.

## Fix Applied

**Commit**: `f9ff558` — fix(i18n): Update to new next-intl API (requestLocale)

Updated i18n/request.ts to use the new API:
```typescript
export default getRequestConfig(async () => {
  const locale = await requestLocale();
  return {
    locale,
    messages: (await import(`../locales/${locale}.json`)).default,
  };
});
```
