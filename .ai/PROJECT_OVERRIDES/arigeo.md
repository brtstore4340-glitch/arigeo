# 🔬 Arigeo — Brand Overrides

**Project**: Medical/Laboratory Technology  
**Brand Position**: Scientific precision, innovation, professional, corporate  
**Target Audience**: Medical professionals, hospital admins, researchers

---

## 🎯 Brand Identity

| Attribute | Value |
|-----------|-------|
| **Tone** | Scientific, precise, professional, authoritative |
| **Energy** | Technical, innovative, trustworthy, serious |
| **Personality** | Expert, detailed, solution-focused, evidence-based |
| **Emotional** | Confidence, reliability, advanced, modern |

---

## 🎨 Color Overrides

### Primary Colors
```css
--color-primary-500: #0369a1;       /* Cyan/Blue (science, technology) */
--color-primary-600: #0284c7;       /* Brighter cyan */
--color-accent: #06b6d4;            /* Turquoise (innovation, accuracy) */
--color-secondary: #0f766e;         /* Teal (stability) */
```

### Text & Backgrounds
```css
--color-text-primary: #0c2340;      /* Deep blue (corporate, serious) */
--color-bg-primary: #ffffff;        /* Pure white (sterile, clean) */
--color-bg-secondary: #f0f9ff;      /* Light blue (calm, clinical) */
```

## 🎞️ Photography & Imagery

### Style
- Medical/laboratory/industrial photography
- High precision, no softness
- Blue/cyan color treatment
- Technical equipment, professionals at work
- Always credible, never stock-photo-like

### Never Use
- Fake illustrations
- People in casual settings
- Playful imagery

---

## 🎬 Motion & Animation

### Philosophy
- **Minimal** — only when necessary
- **Precise** — exact timing, professional
- **Professional** — never playful or flashy
- **Corporate** — enhance data visualization, not distract

---

## 🏗️ Layout & Grid

- Desktop-first design
- Professional grid (4 or 6 column)
- Generous whitespace
- Clear information hierarchy
- Data visualization prominent
