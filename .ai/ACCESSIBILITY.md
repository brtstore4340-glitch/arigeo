# Accessibility (WCAG 2.2 AA) Checklist

Universal requirements:
- Color contrast: 4.5:1 for normal text, 3:1 for large text (WCAG AA)
- Focus indicators: Always visible, min 2px
- Keyboard navigation: All interactive elements accessible
- Semantic HTML: Use proper tags (<button>, <nav>, <header>)
- ARIA labels: Where content is not text
- Alt text: All images need meaningful alt text
- Form labels: Every input has associated label
- Page structure: Logical heading hierarchy (h1→h2→h3)
- Skip links: Option to skip navigation (where applicable)
- No text only via color: Use patterns or text in addition to color
- Movement: Respect prefers-reduced-motion
- Touch targets: Min 44×44px on mobile
- Text resizing: Works at 200% zoom

**Reference**: WCAG 2.2 Level AA guidelines
