QUICK START (5 MINUTES)

STEP 1: Get Free API Key
─────────────────────────

  OPTION A: Claude (Best for Thai)
    → Go to: https://console.anthropic.com
    → Create API Key
    → Copy key like: sk-ant-v0-...

  OPTION B: Grok (Fastest, Cheapest)
    → Go to: https://console.x.ai
    → Create API Key
    → Copy key like: xai-...

  OPTION C: Gemini (Free Tier)
    → Go to: https://ai.google.dev
    → Get API Key (no credit card)
    → Copy key like: AIza...

STEP 2: Set Environment Variable
─────────────────────────────────

  In PowerShell:

  For Claude:
    $env:ANTHROPIC_API_KEY = "sk-ant-v0-..."

  For Grok:
    $env:GROK_API_KEY = "xai-..."

  For Gemini:
    $env:GOOGLE_AI_KEY = "AIza..."

STEP 3: Run Jarvis with AI
──────────────────────────

  cd "D:\01 Main Work\Boots\Agentic AI\mission-control\tools\jarvis-staging"

  .\START_JARVIS_AI.ps1 -Command "help"
  .\START_JARVIS_AI.ps1 -Command "open chrome"
  .\START_JARVIS_AI.ps1 -Command "take a screenshot"

STEP 4: Try Natural Language
────────────────────────────

  These now all work (AI understands intent!):

  .\START_JARVIS_AI.ps1 -Command "can you open the chrome browser?"
  .\START_JARVIS_AI.ps1 -Command "please take a screenshot for me"
  .\START_JARVIS_AI.ps1 -Command "search for thai language resources"

STEP 5: Try Thai (with Claude)
──────────────────────────────

SWITCHING PROVIDERS
════════════════════════════════════════════════════════════════════════

  # Use Claude (default, best Thai)
  .\START_JARVIS_AI.ps1 -Command "help" -IntentProvider claude

  # Use Grok (fastest)
  .\START_JARVIS_AI.ps1 -Command "help" -IntentProvider grok

  # Use Gemini (free tier)
  .\START_JARVIS_AI.ps1 -Command "help" -IntentProvider gemini

  # Disable AI, use regex only
  .\START_JARVIS_AI.ps1 -Command "help" -UseAI:$false

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

ERROR: API Key not found
  FIX: $env:ANTHROPIC_API_KEY = "your-key"

ERROR: AI parser fails, falling back to regex
  EXPECTED: This is normal if API is down or rate-limited
  Try: Use different provider or retry later

ERROR: Thai command not understood
  FIX: Use Claude (best Thai support)
  .\START_JARVIS_AI.ps1 -Command "..." -IntentProvider claude

SLOW RESPONSES
  TRY: Switch to faster provider
  .\START_JARVIS_AI.ps1 -Command "..." -IntentProvider grok
