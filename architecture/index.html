CORE PRINCIPLE

บริหารข้อมูลจากส่วนกลาง และนำไปใช้งานตามวัตถุประสงค์

เมื่อทีมการตลาดปรับปรุงข้อมูลผลิตภัณฑ์ Captain Maid ใน CMS ข้อมูลที่ผ่านการตรวจสอบและอนุมัติแล้วสามารถนำไปแสดงบน ARIGEO และ Captain Maid ในรูปแบบที่เหมาะสม โดยอ้างอิงจากแหล่งข้อมูลเดียวกัน

SYSTEM 01

ARIGEO

Corporate website และ Brand Portfolio Gateway

เว็บไซต์หลักขององค์กร สื่อสาร Purpose, Mission, Vision, Values และเชื่อมผู้ชมไปยัง Captain Maid, GenuLeaf และ CeraTory โดยไม่ทำตัวเป็นร้านค้าออนไลน์ที่ซับซ้อน

ROLE: TRUST · DISCOVERY · CORPORATE COMMUNICATION

ฟังก์ชันสำหรับผู้เข้าชม

  • Homepage แนะนำองค์กร หมวด Household และ Skincare
  • About / ARIGEO Way: Purpose, Mission, Vision, Values
  • Brand portfolio และหน้า Captain Maid, GenuLeaf, CeraTory
  • Product discovery พร้อม filter ตาม brand/category/concern
  • Innovation, Sustainability, Newsroom, Careers และ Contact
  • เปลี่ยนภาษาไทย–อังกฤษโดยคงเส้นทางหน้าปัจจุบัน

คุณภาพและการค้นหา

  • SEO metadata, canonical, hreflang และ social metadata
  • Organization, Breadcrumb, Article structured data เมื่อข้อมูลครบ
  • Responsive desktop/tablet/mobile และ keyboard navigation
  • typed fallback หาก CMS ติดต่อไม่ได้
  • ไม่แสดงราคา rating stock หรือ claim ที่ยังไม่อนุมัติ
  • GA4/GTM events สำหรับ brand click, product view, contact

SYSTEM 03

CAPTAIN MAID

Consumer website ที่ช่วยให้เลือกสินค้าได้ง่าย

เน้นประสบการณ์ผู้บริโภค ตั้งแต่เห็นภาพการใช้งาน ค้นหาโซลูชัน อ่านวิธีใช้และความปลอดภัย ไปจนถึงคลิกซื้อผ่านช่องทางจำหน่ายที่บริษัทกำหนด

ROLE: PRODUCT DISCOVERY · EDUCATION · SHOPPING GATEWAY

ประสบการณ์หน้าเว็บไซต์

  • Hero slider 5 ภาพ พร้อม auto-rotation และปุ่มควบคุม
  • Trust benefits และหลักการคุณภาพของแบรนด์
  • หมวดพื้น ห้องน้ำ ครัว กระจก ฆ่าเชื้อ และล้างจาน
  • Solutions by room / problem
  • Product listing/detail วิธีใช้ ประโยชน์ ขนาด ความปลอดภัย
  • บทความ FAQ รีวิว เรื่องราวแบรนด์ และไทย–อังกฤษ

Commerce แบบควบคุมความเสี่ยง

  • Shop Now เชื่อม Lazada, Shopee หรือช่องทางที่อนุมัติ
  • ราคา availability rating และ review แสดงเมื่อยืนยันแล้ว
  • รองรับ variant, scent, size และ SKU
  • ไม่มี checkout, payment, order หรือ inventory ใน scope
  • next/image, responsive sizes และ lazy loading
  • CMS adapter แปลงข้อมูลให้ตรง component contract

ROLE-BASED ACCESS CONTROL

แต่ละคนเห็นและแก้เฉพาะส่วนที่ได้รับมอบหมาย

บัญชีผู้ใช้ผูกกับ role และรายการเว็บไซต์ arigeo / captain-maid ลดความเสี่ยงจากการแก้ข้อมูลข้ามแบรนด์

บทบาทขอบเขตสิทธิ์หลัก
Adminทั้งสองเว็บไซต์ผู้ใช้ โครงสร้างข้อมูล แบรนด์ ผลิตภัณฑ์ สื่อ และการตั้งค่าทั้งหมด
Marketing Editorเว็บไซต์ที่มอบหมายหน้า บทความ FAQ แบนเนอร์ เมนู ติดต่อ และเตรียมเนื้อหาเข้าตรวจ
Graphic Editorเว็บไซต์ที่มอบหมายภาพ แบนเนอร์ alt text เครดิต และข้อมูลสิทธิ์ ตาม policy
Viewerเว็บไซต์ที่มอบหมายอ่านและตรวจสอบ แต่ไม่แก้ไขหรือลบ

Baseline ปัจจุบันจำกัด master data ที่มีผลต่อทั้งสองเว็บไซต์ เช่น Products, Brands, Variants และ Media rights ให้ Admin ดูแล ส่วน editor ใช้ site-scoped collections; permission matrix ต้องผ่าน staging acceptance test ก่อนเปิดบัญชีจริง

CONTENT LIFECYCLE

จากร่างภายใน สู่หน้าเว็บจริงอย่างควบคุมได้

ป้องกันข้อความ รูป ราคา หรือ claim ที่ยังไม่อนุมัติหลุดขึ้น production

  1. 01Create draft

    Editor สร้างหรือแก้ เนื้อหายังไม่สาธารณะ

  2. 02Validate & preview

    ตรวจ field ภาษา รูป alt และหน้า preview

  3. 03Review

    ตรวจแบรนด์ claim ราคา และช่องทางซื้อ

  4. 04Approve & publish

    อนุมัติและบันทึก version

  5. 05Revalidate

    Webhook ล้าง cache เฉพาะส่วน

  6. 06Monitor & rollback

    ตรวจ log และย้อน version ได้

SECURITY, QUALITY & OPERATIONS

ออกแบบให้ปลอดภัย ดูแลง่าย และตรวจสอบย้อนหลังได้

01

Identity & access

Payload authentication, session/API key, role และ site scope จำกัดผู้ใช้ตามหน้าที่

02

Origin protection

CORS และ CSRF เฉพาะ domain ที่อนุญาต เก็บ secret ใน environment variables

03

Content integrity

draft/version, verified flags, claim support และ media usage rights

04

Resilience

frontend cache, graceful fallback และแยก deployment ลดผลกระทบข้ามระบบ

05

Performance

Vercel CDN, ISR, optimized images และ lazy loading เพื่อ Core Web Vitals

06

Governance

staging, schema validation, migration, backup/restore และ rollback checklist
